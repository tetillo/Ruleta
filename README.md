# Ruleta

Aplicación web de una ruleta hecha con JSP (Java) y CSS, creada con Eclipse como práctica de clase.

## Qué contiene

- `Main.jsp`: página principal.
- `Generar_resultados.jsp`: página para generar los resultados.
- `Ver_numeros.jsp`: página para ver los números.
- `Visualizar_estadisticas.jsp`: página de estadísticas.
- `Main.css`: estilos.
- Incluye el driver JDBC de Oracle (`ojdbc8.jar`) para conectar con base de datos.

## Tecnologías

Java, JSP, CSS, JDBC. Proyecto en formato Eclipse (`Práctica_7AADD`).
